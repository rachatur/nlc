# Operational Playbooks

## Booking → Check-in → Check-out
1. Create booking (availability + rate plan).
2. Confirm payment or guarantee.
3. Check-in (assign room, issue key).
4. In-stay charges (restaurant, room service).
5. Check-out (invoice, payment, feedback).

## Room Service → Billing
1. Order created via POS or room service.
2. Kitchen prepares and updates status.
3. Delivery marks order completed.
4. Charges auto-post to guest folio.

## Inventory → Waste → Laundry
1. Inventory usage logged by department.
2. Waste entries tracked with category.
3. Laundry tickets adjust linen counts.
4. Reports generated for audits.

## Travel Desk
1. Create request (taxi/tour).
2. Assign partner and commission.
3. Close request with payment status.
