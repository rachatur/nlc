# Components & UX Patterns

## Core UI Components
- **Page Shell:** left rail + top bar.
- **KPI Cards:** occupancy, ARR, RevPAR, pending check-ins.
- **Task Drawer:** quick actions without leaving context.
- **Status Chips:** unified across rooms, bookings, and orders.
- **Timeline Cards:** booking and service history.

## Interaction Patterns
- **Stepper flows** for multi-step actions (booking, check-in).
- **Split views** for counter workflows (guest info + room allocation).
- **Queue views** for room service and housekeeping.
- **Alert badges** for low stock and SLA breaches.

## Consistency Rules
- Reuse the same status chips across all modules.
- Present actions in the same order: primary → secondary → destructive.
- Use consistent terminology for guests, rooms, and invoices.
