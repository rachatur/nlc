# Brand System

## Brand Tokens
- **Primary:** `#1E5EFF` (brand blue)
- **Accent:** `#F6A609` (warm gold)
- **Success:** `#22C55E`
- **Warning:** `#F97316`
- **Danger:** `#EF4444`
- **Background:** `#F8FAFC`
- **Card:** `#FFFFFF`

## Typography
- **Headings:** Inter Semibold
- **Body:** Inter Regular
- **Numeric emphasis:** Inter Medium

## Iconography & Imagery
- Use line icons for quick scanning.
- Hospitality imagery should be subtle and secondary to data.

## Tone & Voice
- Friendly, professional, and efficient.
- Use action labels that reflect outcomes ("Assign Housekeeping", "Create Booking").
